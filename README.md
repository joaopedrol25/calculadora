# 🧮 Calculadora em C

Este é um projeto de **calculadora em C**, que estou desenvolvendo e melhorando ao longo da minha jornada de aprendizado em programação.  
O objetivo é praticar **lógica de programação**, **estruturas de controle** e **boas práticas em C**, evoluindo o código conforme ganho mais conhecimento. 🚀

---

## 📌 Funcionalidades atuais
✅ Operações básicas:  
- ➗ Divisão  
- ✖️ Multiplicação  
- ➕ Adição  
- ➖ Subtração  
- ⬆️ Exponenciação (potência)

---

## 🎯 Funcionalidades planejadas
🔜 Conforme eu aprender mais, quero adicionar:  
- ✔️ Raiz quadrada e funções matemáticas avançadas  
- ✔️ Interface em linha de comando mais interativa  
- ✔️ Tratamento de erros (ex: divisão por zero)  
- ✔️ Histórico de cálculos  
- ✔️ Implementação em outras linguagens (C++, Python...)  

---

## ⚙️ Como compilar e executar
No terminal, compile o código com o `gcc` e depois execute:

```bash
gcc calculadora.c -o calculadora
./calculadora
